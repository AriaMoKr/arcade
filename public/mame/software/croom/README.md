# Concentration Room

`croom.nes`: Concentration Room 0.02 (2010), a card-matching game for the Nintendo Entertainment
System by Damian Yerrick, exactly as he published it in
https://pineight.com/croom/ConcentrationRoom-0.02.zip (SHA-1
`92a5e15d7297f7fec8b23d5d923588348100339e`). Its source is in that zip (`src/`, `tools/` and the
makefile) and at https://github.com/pinobatch/croom-nes.
