# Alex vs Bus: The Race

`alexvsbus-pre3.md`: Alex vs Bus: The Race for the Sega Mega Drive (Genesis), its release pre3
(2026), by Alexandre Almeida (M374LX): a platform runner, in which Alex, who depends on a developing
country's public transport, runs to catch his bus before it leaves without him. Exactly as he
published it, in the release at https://github.com/M374LX/alexvsbus-md/releases/tag/pre3
(`alexvsbus-md-pre3.zip`; the ROM's SHA-1 `66f6ad080815a018f307aa3b197a17c478a54f85`, 512 KB). It
is the Mega Drive port of his game for computers, https://github.com/M374LX/alexvsbus.

Its source, the Corresponding Source of that release, is served beside it:
[`alexvsbus-md-pre3-source.zip`](alexvsbus-md-pre3-source.zip), the repository at the tag `pre3`
(commit `0dc019c0e82682d67bcbd978ccc5189b92b963dd`), as GitHub makes it at
https://github.com/M374LX/alexvsbus-md/archive/refs/tags/pre3.zip. Its README says how to build it
(vasm, with its Motorola syntax, and the `fix-rom` tool in `tools/`). Its licences are beside it as
the release gives them: the notice, [`LICENSE.txt`](LICENSE.txt), and the full texts it names,
[`docs/licenses/GPL-3.0.txt`](docs/licenses/GPL-3.0.txt) and
[`docs/licenses/CC-BY-SA-4.0.txt`](docs/licenses/CC-BY-SA-4.0.txt).
