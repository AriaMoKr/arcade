# Thwaite

`thwaite.nes`: Thwaite 0.04 (2018), a game for the Nintendo Entertainment System by Damian Yerrick,
in which you shoot down the missiles falling on a small town with fireworks: exactly as he published
it, the release at https://github.com/pinobatch/thwaite-nes/releases/tag/v0.04 (SHA-1
`64cb0faa5e2c9788a855454a4070c797659dd425`).

Its source, the Corresponding Source of that release, is served beside it:
[`thwaite-nes-0.04.zip`](thwaite-nes-0.04.zip), the repository at the tag `v0.04` (commit
`ccd27ccbe3e201755b86c1b5f932b2e11ba74110`), as GitHub makes it at
https://github.com/pinobatch/thwaite-nes/archive/refs/tags/v0.04.zip. Its README and `USAGE.html`
say how to build it (GNU Make, Python 3 with Pillow, and ca65 from cc65) and how to play it. The
licence it is under, the GNU General Public License, version 3, is [`LICENSE.txt`](LICENSE.txt), as
in the zip.

Its manual's warning: Thwaite makes explosions and smoke appear translucent by flickering them, and a
very small percentage of people have seizures after looking at flickering patterns. The room says
that its explosions flicker wherever it names the game: beside its button in the card, on the panel
beside the cabinet, and to a screen reader in the view's description and its picture's.
